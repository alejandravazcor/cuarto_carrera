# Jean-Paul Sartre (1905-1980)

| | |
|---|---|
| **Vida** | París |
| **Corriente** | Existencialismo |
| **Obras clave** | *La náusea* (1938) · ***El ser y la nada*** (1943) · ***El existencialismo es un humanismo*** (1945) · *Crítica de la razón dialéctica* (1960) |
| **Influencias** | Kierkegaard → Husserl → **Heidegger** → Sartre |
| **Pregunta 4 típica** | Relación con **Heidegger** |

## Conceptos clave
- **Ser en-sí** (las cosas: es lo que es) vs **ser para-sí** (la conciencia: nada, proyecto)
- **La existencia precede a la esencia** (ejemplo del cortapapeles)
- **Condenado a ser libre** · facticidad vs libertad
- **Angustia, desamparo, desesperación** · **náusea** · **mala fe**
