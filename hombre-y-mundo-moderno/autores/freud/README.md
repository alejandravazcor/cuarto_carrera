# Sigmund Freud (1856-1939)

| | |
|---|---|
| **Vida** | Freiberg (Moravia) · Viena · Londres |
| **Corriente** | Psicoanálisis · maestro de la sospecha |
| **Obras clave** | *Estudios sobre la histeria* (1895) · ***La interpretación de los sueños*** (1900) · *Tótem y tabú* (1913) · *El yo y el ello* (1923) · *El malestar en la cultura* (1930) |
| **Influencias** | Brücke · Charcot · Breuer · Darwin · Schopenhauer → Freud |
| **Pregunta 4 típica** | Relación con **Nietzsche** |

## Conceptos clave
- **Inconsciente** y **represión** · 1.ª tópica (consciente / preconsciente / inconsciente)
- Vías de acceso: **sueños**, **lapsus**, **chistes** · psicoanálisis · **transferencia**
- **Pulsiones** · principio del placer / de realidad · **Eros vs Thanatos**
- 2.ª tópica: **ello / yo / superyó** · religión como **ilusión**
