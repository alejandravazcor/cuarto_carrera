# Hombre y Mundo Moderno

Apuntes, desarrollos y material de estudio de la asignatura **Hombre y Mundo Moderno** (4.º curso · Informática + ADE).

Autores del temario: **Sartre · Freud · Nietzsche · Marx**.

## 🎯 Cómo usar este repositorio

| Si vas a… | Usa |
|---|---|
| Hacer el **trabajo** (con apuntes) | `autores/<autor>/desarrollo-trabajo.md` impreso |
| Estudiar para el **parcial** (sin apuntes) | `autores/<autor>/chuleta-parcial.md` |
| Entender qué piden en cada pregunta | [`guia-examen/estructura-examen.md`](guia-examen/estructura-examen.md) |
| Ver un examen modelo resuelto | [`guia-examen/ejemplo-heidegger.md`](guia-examen/ejemplo-heidegger.md) |

## 📝 Estructura del examen (5 preguntas × 2 puntos · 120 min)

1. **Contexto**: época, acontecimientos históricos e influencias (explicadas, no enumeradas).
2. **Doctrina** (I): conceptos centrales, sin opinión.
3. **Doctrina** (II) / clasificación: ¿por qué es existencialista / maestro de la sospecha?
4. **Relación con otro autor**: puntos comunes y diferencias.
5. **Comentario crítico** + consecuencias antropológicas + definir **ser humano** y **persona**.
