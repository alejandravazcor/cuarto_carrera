# Friedrich Nietzsche (1844-1900)

| | |
|---|---|
| **Vida** | Röcken (Prusia) · Basilea · Turín · Weimar |
| **Corriente** | Vitalismo · maestro de la sospecha |
| **Obras clave** | *El nacimiento de la tragedia* (1872) · ***La gaya ciencia*** (1882) · ***Así habló Zaratustra*** (1883-85) · ***La genealogía de la moral*** (1887) · *El Anticristo* (1888) |
| **Influencias** | Grecia trágica · Heráclito · Schopenhauer · Wagner → Nietzsche |
| **Pregunta 4 típica** | Relación con **Sartre** |

## Conceptos clave
- **Moral de señores vs moral de esclavos** · **resentimiento**
- **Dios ha muerto** · nihilismo · transmutación de los valores
- **Voluntad de poder** vs voluntad de verdad
- **Tres transformaciones** · **superhombre** · **eterno retorno**
